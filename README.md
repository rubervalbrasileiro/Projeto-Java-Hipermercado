# 🏬 Projeto Hipermercado

Sistema desenvolvido em Java para gerenciamento de produtos de hipermercado, com integração ao banco de dados MySQL e interface gráfica desktop.

## 🎯 Objetivo do Projeto

Projeto desenvolvido com finalidade educacional, visando o treinamento prático e a consolidação de conhecimentos em Java, banco de dados e arquitetura de software.

## 🧩 Tecnologias Utilizadas

- Java SE
- MySQL
- JDBC
- Swing
- Programação Orientada a Objetos
- Collections Framework

## 🏗 Arquitetura do Projeto

O sistema segue uma arquitetura em camadas:

- **conexao** → Gerenciamento da conexão com o banco de dados  
- **modelDAO** → Acesso a dados (DAO)  
- **models** → Entidades do sistema  
- **services** → Regras de negócio  
- **views** → Interface gráfica (Swing)

## ⚙ Funcionalidades

- Cadastro de produtos
- Listagem de produtos ativos
- Atualização de dados
- Inativação lógica de produtos
- Filtro dinâmico de produtos
- Comparação de preços entre supermercados
